# 🎓 BEdu — Learn. Prepare. Get Hired.

**BEdu (Bachelors Education)** is a student-focused career preparation 
platform designed to help graduating students **learn skills, practice 
assessments, and discover career opportunities** in one place.

> **Learn → Practice → Explore → Grow**

---

## 🌟 What is BEdu?

Graduating students often use different platforms for learning, aptitude 
practice, technical preparation, and job searching.

**BEdu brings these activities together in one simple platform.**

With BEdu, students can:

* 📚 Explore learning resources
* 📝 Take technical and aptitude assessments
* 📊 Track assessment scores and learning progress
* 💼 Explore internships and job opportunities
* 👤 Maintain a student profile
* 🎯 Prepare for their next career step

---

## ✨ Features

### 📊 Student Dashboard

A central dashboard showing:

* Learning progress
* Assessment performance
* Average score
* Recent activity
* Career opportunities

### 📚 Learning Resources

Students can browse resources by category:

* Programming
* Database
* Aptitude
* Interview Preparation
* Career Preparation

Search and category filters make it easier to find relevant content.

### 📝 Online Assessments

BEdu currently includes:

* ☕ Java Fundamentals
* 🗄️ SQL Basics
* 🧮 Quantitative Aptitude

Each assessment contains **10 questions** with a **10-minute timer**.

After completing an assessment, students can see:

* Score
* Correct answers
* Wrong answers
* Percentage
* Result message

### 💼 Career Opportunities

Students can explore sample opportunities using:

* Search
* Opportunity type filters
* Skills
* Location
* Job type

### 👤 Student Profile

The profile section allows students to view and edit basic information 
such as:

* Name
* College
* Degree
* Graduation year
* Location
* Skills

## 🚀 How to Use

### 1. Open BEdu

Open:

```text
index.html
```

in a web browser.

### 2. Explore the Dashboard

Click **Explore BEdu** to access the student dashboard.

### 3. Learn

Open **Resources** and browse learning materials by category.

### 4. Practice

Go to **Assessments** and choose:

* Java
* SQL
* Quantitative Aptitude

### 5. Check Your Results

After completing an assessment, your score is saved in the browser and 
reflected on the dashboard.

### 6. Explore Opportunities

Visit **Opportunities** to browse available sample career opportunities.
